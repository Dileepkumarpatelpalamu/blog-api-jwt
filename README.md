Blog API with JWT Authentication (Django REST Framework)
Introduction

This project implements a Blog API using Django REST Framework (DRF) with JWT authentication. Users can register, log in, and manage blog posts securely using RESTful endpoints and JSON Web Tokens.

Features

• User Registration and Login with JWT
• Create, Read, Update, and Delete Blog Posts
• Token-based access for protected endpoints
• Public endpoints for viewing blogs
• Secure API implementation using DRF authentication

Tech Stack

• Backend: Django REST Framework
• Authentication: JSON Web Tokens JWT
• Language: Python
• Database: Built-in Django support SQLite
